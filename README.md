# lanzaforge-core

> the frontend source code for <https://www.lanzaforge.org>.

## Download

First, clone the repository:

```sh
git clone https://github.com/Lanzaforge/lanzaforge-core.git
# or by using the GitHub CLI:
gh repo clone Lanzaforge/lanzaforge-core
```

## Install

Enter the directory and install the required dependencies.

> **Note:** This project was built with `pnpm` in mind. Using `pnpm` is recommended.

```sh
pnpm install
# or
npm install
```

## Watch

```sh
pnpm run dev
# or
npm run dev
```
